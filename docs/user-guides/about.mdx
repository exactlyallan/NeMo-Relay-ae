These guides connect NeMo Relay capabilities to outcomes that an enterprise
platform team needs to deliver. Start with the goal that matches your deployment:

- **Export agent activity to an observability platform.** Connect an existing
  Relay telemetry source to the platform your team uses, then check that agent,
  model, and tool activity appears in one trace.
- **Govern coding agents across workstations.** Bring supported coding harnesses
  under a managed daemon and apply your organization's telemetry, privacy, and
  cost-attribution settings.
- **Evaluate model routing against a fixed-model baseline.** Route eligible
  model calls with Switchyard and compare completed-task cost and quality before
  changing a production policy.

Each guide identifies the decisions and evidence that matter to its goal and
links to the setup and configuration pages that own the detailed instructions.
Use [Getting Started](/getting-started/about) if you need to choose your first
Relay integration. Keep the [Daemon](/daemon/about) and
[Configure Plugins](/configure-plugins/about) sections available when planning a
managed deployment.

## Runnable companion examples

Each guide names a concrete example environment, the result to inspect, and the
choices you can replace. The example files live beside the guide in this
repository and can run on an ordinary Brev VM or a comparable Linux host.
A premade Brev Launchable is not required. The same workload and configuration
files serve both environments; credentials and host provisioning come from your
own deployment.

Use the examples to inspect a realistic slice of the workflow, then adapt the
harness, model provider, receiving tier, and topology to your organization.
The selected products are example choices, rather than prerequisites for every
Relay deployment. A successful example run verifies its stated scope; it does
not establish coverage for every workstation, harness, or provider path.
